Applied Genetics — Help & Documentation

A VB6 desktop toolkit for DNA / RNA / protein sequence analysis: restriction site detection, codon translation, repeat & palindrome finding, primer design, and gel electrophoresis simulation. Preserved here for historical purposes.

v1.2 beta © 2008–2009

Overview

Applied Genetics is a single-window VB6 application (form genetica.frm, project name AG) built around a large text/RTF input box holding a DNA, RNA, or protein sequence, and a tabbed side panel offering four families of analysis: restriction enzymes, gene/frame-shift tools, inverse-sequence search, and repeat search. Results are streamed into an OUTPUT window as formatted, colour-highlighted text, and can optionally be represented as a simulated agarose gel.

The program was distributed as shareware with a 30-use trial counter, an online activation flow, and an offline CD-key fallback.

Trial & Activation

On startup, the Trial form checks a usage counter before handing off to the main window.

Trial window buttons

ValidationContinueInternetExit
  • Continue — runs the program in trial mode and decrements the remaining-use counter ("The program can be used N more times").
  • Validation — opens the key-entry screen (Trial_COD.frm) where a purchased activation key (username + code) can be entered and verified.
  • Internet — link to obtain an activation key online.
The trial counter is stored both in the registry (HKCU\Software\VB and VBA Program Settings\WinSys\system) and in a small marker file named sys_exp.dll written to the OS system folder. Both must agree, or the program refuses to run ("The program has already been installed on this PC!"). On 64-bit Windows, remember that this 32-bit app is transparently redirected from System32 to SysWOW64 for that file.

Manual Editing & Sequence Conversions

Above the main sequence box, a row of single-letter buttons converts or annotates the current selection or full sequence:

RFSG AntisensReversARN-ADNADN-ARNADN-AA
  • Antisens — computes the antisense strand starting from a given position.
  • Revers — computes the reversed strand.
  • ARN-ADN / ADN-ARN — RNA→DNA and DNA→RNA back-and-forth conversion.
  • ADN-AA — translates a DNA sequence to amino acids using the current codon table (see Codons & Amino Acids).

A live side panel ("Real time changes") shows running counts of A / T / C / G / U, the selection length, an approximate primer Tm, and G+C% as you select text in the sequence box.

Analysis Tabs

The right-hand panel has four tabs. All four share the same Start/Stop toggle button (Testeaza_CODUL) and mirror it on a second overlapping button (Run_Primar).

Enzime — Restriction Enzymes

Detects restriction-enzyme recognition sites in the sequence, in both the normal (5'→3') and complementary (3'→5') directions, and can simulate deletion/insertion around a chosen enzyme's cleavage point (marked with * in its recognition sequence).

  • DETECT RESTRICTION — scans for all recognition sites of the selected enzyme(s) from the enzyme database.
  • Deletion / Insertion, each in 5'→3' and 3'→5' — explores possible restriction sites after simulating a deletion or insertion of a given distance around existing sites.
  • Results are streamed to OUTPUT with per-direction and combined totals, e.g. "Total restriction sites existing in the 5'-3' and 3'-5' directions: [4]", and each fragment can be represented on the simulated GEL.

Gene

  • Frame Shift — offsets the reading frame used for codon-by-codon analysis.
  • Delimit AUG — locates and brackets START codons in the sequence.
  • START / STOP codon notation — customizable bracket markers, e.g. [+POSITIONb+] / [-POSITIONb-], used to tag the location of start and stop codons directly inside the displayed sequence.

S.I. → I.S. (Inverse Sequences)

Brute-forces every possible nucleotide combination between a configurable start and end length (character set, target length, optional starting combination) and checks each one against the sequence for inverse/palindromic repeats (VER_PALINDROM_DISTANTA). Matches are reported with their position and appended to OUTPUT via SECVENTE_INVERSE. A live status panel shows current combination, combinations/second, and totals. An optional graphical view ("Show I.S. in graphic format") mirrors progress on a second window (Lista_cu_geluri.frm).

S.R. → R.S. (Repetitive Sequences)

Same brute-force engine as I.S., but checks each generated combination for direct repeats (VER_REPETITIE_DISTANTA / REPETITII), constrained by "At least" / "At most" repeat-count fields. Matches are highlighted directly in the sequence box and logged to OUTPUT, e.g. "Repeats in position:[…] - [AAAA * 12] …".

Stopping a running scan: both I.S. and R.S. searches can take a long time on long sequences with common motifs. Press the same Start/Stop button again to abort — the click is detected between iterations of the brute-force loop and inside the highlight-scanning routines, so it may take a moment to register on a very "busy" iteration rather than stopping instantly.

GEL Simulation

A dedicated panel renders detected fragments as bands on a simulated agarose gel, alongside a live info box showing the current enzyme, fragment index, and migration distance ("Migration : … b - … mm"). Band/segment colours are configurable per algorithm (deletion / insertion / normal, each in both directions) from the Options window.

Segment interaction: left-click a gel segment to change its background colour; right-click to change its text colour. These segments represent the colours of the different sequence types found by the various algorithms.

Primer Design — Melting Temperature (Tm)

The Primer panel calculates the melting temperature of a selected sequence using either of two formulas, switchable from a dropdown:

Recommended formula

Tm = 81.5 + 16.6 × (log₁₀ [Na⁺]) + 0.41 × (%G+C) − 675 / n

Approximate formula

Tm = 4 × (G + C) + 2 × (A + T)

where n is the total number of selected nucleotides and [Na⁺] is the molar Na⁺ concentration. The live panel shows the current primer length, Tm, and G+C% as you make a selection in the sequence box.

Version Notes — Windows 11 Port

This build has been updated from the original 2008–2009 sources to run cleanly under modern Windows and VB6 IDEs. Notable fixes:

  • Name-conflict warnings on load — mismatched casing between a form's Begin VB.Form declaration and its Attribute VB_Name (e.g. Principal vs principal) resolved for genetica.frm and Actiuni.frm.
  • Run-time error 5 in the brute-force engine (clsBruteforce.BruteForce) — guarded against re-entrant calls triggered by DoEvents.
  • Run-time error 5 in restriction-site extraction (Functii_ENZIME.Restricteaza_COD) — Mid$ start/length arguments are now clamped to valid ranges.
  • Stop button unresponsive on I.S. / R.S. tabs — the internal highlight scanning loops in REPETITII and SECVENTE_INVERSE (in OUT.bas) now check for a Stop request on every scan step, matching the existing convention used by the Enzime tab.
  • Trial counter false positives on 64-bit Windows — the trial marker file lives in the WOW64-redirected SysWOW64 folder for this 32-bit build, not the real System32; both the app and the companion reset tool account for this.
  • UI translated to English — all form captions, tooltips, dynamically-set labels, and message boxes were translated from the original Romanian, preserving line lengths and internal markers (e.g. [#PROCESARE#]) untouched.
